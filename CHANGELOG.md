# Changelog

All notable changes to this project are documented here.

## Unreleased

### Added

- Importable Go client for Colab runtime allocation, execution, contents API, automation, SSH bridge, and usage data.
- `colab` CLI wrapper with runtime, execution, workspace, and utility commands.
- OAuth2 and Application Default Credentials authentication strategies.
- Protocol mock tests and opt-in live integration test.

### Changed

- Canonical Go module path: `github.com/thangvv-tech/go-colab`.
- Release/version policy is independent from any Python package or registry.
